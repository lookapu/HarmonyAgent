# Agent 能力包

能力包把常见开发目标收敛为最小工具集合和可验收执行策略。当前包含：

| 能力包 | 目标 | 典型闭环 |
|---|---|---|
| `project_understanding` | 项目理解 | 目录 → 工程信息 → 模块 → 扫描 → 定位 → 精读 |
| `compile_fix` | 编译/缺陷修复 | 诊断 → 日志 → 精读 → 小步编辑 → 检查 → 构建/测试 |
| `feature_development` | 功能开发 | 定位 → 符号 → 实现 → 测试 → 构建 → 审查 |
| `refactor` | 安全重构 | 全局扫描 → 引用 → 预览 → 批量编辑 → 格式化 → 回归 |
| `build_deploy` | 构建部署 | 环境/SDK/签名 → 构建 → 设备 → 部署 → 启动 → 截图 |
| `device_diagnostics` | 设备诊断 | 设备/应用 → 日志 → 截图/层级 → 性能/崩溃分析 |
| `git_delivery` | Git 交付 | 状态/diff → 审查/密钥扫描 → 门禁 → 提交 → 按需推送 → 远端确认 |

每个能力包在代码中声明：触发词、最小工具集、推荐顺序、停止条件和验收条件。公共工具仅保留计划、待办、提问及按需帮助 7 项。

系统提示与 OpenAI 原生 function schema 使用同一个选择器。任务可组合多个能力包，但单轮最多暴露 40 个注册工具；没有明确匹配时仅加载项目理解包。工具仍可通过 `tool_help`/`tool_list` 按需发现，避免裁剪导致能力永久不可达。

回归测试保证能力包引用的工具全部存在、控制字段非空、选择结果有界，并验证编译修复不会意外暴露 `git_push`，Git 交付才会加载推送能力。
