# 工具选择排序

HarmonyAgent 先由任务能力包和当前执行阶段生成候选工具，再对候选集排序，每轮最多向模型暴露 32 个工具。

排序信号包括：

- 能力包推荐顺序，作为冷启动先验；
- 最近 90 天调用成功率；
- 历史平均耗时；
- 历史平均结果大小折算的预计 token 成本；
- 工具契约声明的只读、写入或破坏性副作用；
- 当前会话是否位于 HarmonyOS/OpenHarmony 工程、Git 仓库，以及近期是否已确认设备可用。

历史数据缺失时不会虚构成功率或成本，而是保留能力包顺序。环境不满足时工具只会降权，不会从候选集中永久删除；例如 `list_devices` 始终可用于发现设备。阶段过滤仍是硬边界，排序不能提前解锁写入、破坏性操作或 `git_push`。

每轮前八名及其分项理由写入 `tool_ranking` 运行日志，便于复盘为什么某个工具被优先暴露。日志不包含工具参数或用户内容。
