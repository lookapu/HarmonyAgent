# 工具目录治理

可靠性面板按选定窗口生成工具治理清单，提供 `fix`、`hide_candidate` 和 `merge_review` 三类动作建议，不自动删除或隐藏工具。

## 判定规则

- 高失败率：窗口内至少调用 5 次，非成功结果占比达到 40%，建议优先修复。
- 长期未使用：工具在窗口前确实有调用历史、当前窗口为零，才列为隐藏候选。新数据库和从未使用的工具不会被批量误报。
- 功能重叠：维护一份保守候选对，当前覆盖构建入口、API 搜索、文档读取和诊断入口；只提示人工审查语义边界。

清单显示工具、关联工具、证据、失败/调用次数及推荐动作，最多 100 条，按高失败、重叠、长期未使用排序。时间窗口复用可靠性面板的 1—365 天选择，默认 30 天。

治理动作必须经过协议兼容评估：合并/隐藏前确认能力包引用、工具 schema、历史 Run 回放和旧版 `ToolResultV2` 消费者不受影响。
